# NER-RESQ

AI-powered logistics resilience and accessibility intelligence platform for the North Eastern Region of India.

## Project Structure

- Frontend - React web application
- Backend - Backend APIs and services
- Ml - Machine learning models
- Gis - GIS and geospatial processing
- Logistics - Logistics optimization
- Simulation - Disaster simulation and digital twin
- Database - Database schemas and migrations
- Tests - Testing
- Docs - Project documentation
- Scripts - Automation and utility scripts
